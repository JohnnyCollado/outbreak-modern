## Grammar as implemented
- `#` to end of line is a comment (so `log` text cannot contain `#`); blank lines skipped; numbers dec or 0x, u32.
- `timeout <secs>`: integer > 0, only once, only before the first step, else parse error. Not a step (no step log).
- `wait vsync <n>`: done at tick >= begin+n (n=0 is immediate).
- `wait mem <ref> <1|2|4> <==|!=> <v>`: checked at begin and each vsync; v must fit the width. ref `*<ptr>[+<off>]` (`+off` optional, default 0); null pointer or out of range = not satisfied.
- `press <b+b..> <n>`: held from begin tick through begin+n-1, released at begin+n, next step at begin+n+1.
- `capture <screen> <n>`: n>0, no `/\:` in screen; done at the first vsync after n frames written.
- `watch <ref> <1|2|4>`: baseline read at begin, logs `[script] watch <ref text> 0x<old>->0x<new> tick=<t>` on each change (unreadable reads skipped).
- `log <text>`: prints `[script] log <text>`. `quit`: sets quit; the script stays on it.
- Instant steps (log, watch, finished waits) chain within the same vsync. Step index i is 0-based; `[script] step <i> line <L> begin tick=<t>`.
- Script ends without quit: buttons released, run continues until timeout (message `step <n> line 0: end of script without quit`).

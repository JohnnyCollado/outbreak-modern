## Deviation: GIF whole-unit splitting (crash fix)
- First pcsx2-sw gate: boot AV (0xC0000005). Temporary SetUnhandledExceptionFilter+StackWalk64 (removed): `GSState::GIFRegHandlerPRIM` <- `GSState::Transfer<3>` GSState.cpp:3457 <- ob_gs_gif <- GifArbiter::drain ps2_gif_arbiter.cpp:63 <- processVIF1Data; read at a page start past the packet vector.
- Cause: Transfer's PACKED do-while (GSState.cpp:3455) runs a handler before checking size; a call ending right after a GIFtag with NLOOP>0 underflows u32 size and overreads. Arbiter hands DMA slices that split tag from data; PCSX2's Gif_Unit only sends whole units.
- Fix: ob_gs_gif(path, ...) carries a per-path tail; only whole GIFtag units (PACKED nloop*nreg, REGLIST ceil(nloop*nreg/2), IMAGE/DISABLE nloop qwords; nreg 0 = 16) go to GSgifTransfer. Bridge signature gained `path`. After the fix: no crash.

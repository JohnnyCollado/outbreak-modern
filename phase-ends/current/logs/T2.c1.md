# T2.c1 log: gate.py, ob.sh gate, manifest window/session

Commit 82a99cb: `tools/gate/gate.py` (new), `tools/gate/refs.py`, `tools/ob.sh`, `docs/ops/gate.md`.

## Changes
- `gate.py`: `compare`, `selftest`, `stamp` and `synth DIR`; exit 0/1/2/5; `--start EPOCH` so the wall time counts from ob.sh's start.
  Defaults for manifest and tolerance resolve against the repo root, not the cwd.
- compare: frames are globbed as `<screen>-<k>.png`. The capture count must equal manifest `window[screen]` (an int also works).
  Ticks come from the `[script] capture <s> k=<k> tick=<t>` lines.
  Refusals print `refused: <problem>` lines, then `gate: refused (<n> problem(s)), exit 2, wall <s> s`.
- selftest, missing layer: colours quantized to 3 bits per channel; components pruned by area x 255 < best score.
  Distance = max channel |component mean - ring median|.
  Shifted glyph: integral image over FIND_EDGES; grid limited to x <= w-26 so the +2 px paste stays inside the image.
  Damage = crop the window and paste it at x+2.
- stamp: sha256 over sorted `label\tsha` lines; labels are root-relative (`src/...`, `t/...`, `up:HEAD`, `up:diff`, `up:untracked/...`).
  Missing inputs hash as `MISSING`. Excluded dirs: `.git .vs build out build-* cmake-build*`. Result: 330 entries, none missing, 0.55 s.
  `cmd_recompile` is matched from `cmd_recompile() {` to the first line that is exactly `}`.
- ob.sh `cmd_gate`: runs recompile in a subshell (`( cmd_recompile )`) because it cds.
  Prints `gate: recompiled in <s> s` or `not recompiled (stamp unchanged)`. Boot/recompile/stamp failures print a final `gate: ..., exit N, wall S s`.
  Usage line at :12; dispatch prints lines 6-12.
- refs.py: `capture_window()` parses `capture <screen> <n>` from `gate/boot.script`; the manifest now has `window` {screen: n} and `session` (ISO).
- Uses `get_flattened_data` instead of `getdata`, which Pillow 12 deprecates.

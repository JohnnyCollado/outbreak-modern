## Notes
- Renderer/device: SW renderer presents through a GSDevice; GetAPIForRenderer(SW) -> GSUtil::GetPreferredRenderer -> D3D::GetPreferredRenderer stub -> VK. So SW also uses the Vulkan device; no D3D anywhere.
- imgui: only PCSX2's 1.93.0 compiled (comment at the block). GSDeviceVK::RenderImGui runs every present, hence the real empty context.
- Smoke: one PACKED GIF packet, NREG=1 A+D x11: FRAME, SCISSOR, TEST (ZTE, ALWAYS), ZBUF (ZMSK), PRIM sprite, a full-frame clear sprite 0x203040 then a 160..480 x 112..336 sprite 0x10E0F0. Basemem also sets SMODE1 CMOD=2 (NTSC): GSState::GetVideoMode reads it, otherwise Unknown. DisableShaderCache=true so every shader goes through shaderc each run.
- gotcha (generalizable): C:\VulkanSDK\1.4.341.1\Bin on PATH has its own shaderc_shared.dll; with the staged DLL removed the smoke still passed. ob.sh runs the smoke with VulkanSDK off PATH. Control: staged DLL removed + SDK off PATH -> "Failed to compile utility pipelines", SW and VK GSopen FAILED, exit 1; restored -> PASS.
- Linked and passed on the first run: the result was checked with that negative control and by the two distinct colours matching exactly.

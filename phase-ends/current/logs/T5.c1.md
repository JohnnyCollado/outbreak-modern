# T5.c1 — gate.py advisory screens

## Changed
- `tools/gate/gate.py`:
  - `tolerance(a)` -> `(d, p, advisory set)`. File = `--tolerance` (default `gate/tolerance.json`). The file is read whenever it exists, so advisory still comes from it when --d/--p are given; it is a Refusal only if the file is missing and d/p are not both given. `advisory` is optional (absent = []); a non-list or a name not in SCREENS -> Refusal `tolerance advisory: unknown screen(s) ...` (exit 2).
  - compare: line suffix ` ADVISORY`; green counted over non-advisory screens only; summary `gate: <g>/<n> gated green, <m> advisory, exit <c>, wall <s> s`; exit 0 iff g == n.
  - selftest: advisory screens' lines end in ` advisory`, not counted in ok/total.
  - synth: frames-advisory (title erased like erased, rest identical) + boot-advisory.log; tol-advisory.json `{d:8,p:0.001,advisory:["title"]}`, tol-none.json `{d:8,p:0.001}`.
  - `--tolerance` on compare/selftest; docstring updated.
- `tools/ob.sh cmd_gate`: `--tolerance PATH` collected with --d/--p into `tol[]`, which goes to both selftest and compare.
- `docs/ops/gate.md` section "gate.py and ob.sh gate": tolerance file shape + advisory, --tolerance, new line formats, exit rule, synth outputs.
- `gate/tolerance.json` not created (frozen in T6).

## Answer
- Tag: v2.9.134 exists. Release page says 21 Oct (year not shown). Commit a81f1aa39fc56ef60dbc913637c74c49c1792033, committer date 2026-10-21T07:48:23Z (author 2026-10-14). Release is marked pre-release.
- GS static lib is feasible: pcsx2/CMakeLists.txt builds GS-sse4, GS-avx, GS-avx2 STATIC libs only when DISABLE_ADVANCE_SIMD=ON on x86. Otherwise GS files are one shared list (single ISA, native flags).
- Single-ISA is possible: leave MULTI_ISA_*_COMPILATION undefined, and CURRENT_ISA becomes isa_native. Default MSVC flags with DISABLE_ADVANCE_SIMD add __SSE4_1__; no AVX2 flag is set on MSVC in the non-multi path.
- Runtime needs: GS.cpp pulls in Host/MTGS/VMManager/Config/ImGui/Input headers, so you must stub those (list below). Shaders are read from disk at EmuFolders::Resources/shaders/{common,vulkan,dx11,opengl}.
- Official Windows build path could not be confirmed as CMake or vcxproj from the sources fetched (README has no build steps; wiki page returned 403). The build-dependencies.bat script exists and targets VS2022 via vcvars64.

## Findings
1. CMake GS lists (pcsx2/CMakeLists.txt):
   - pcsx2GSSources = core GS (GS.cpp, GSState, GSTables, ...), common renderer, Null, HW, GSTextureCacheSW.cpp.
   - pcsx2GSSourcesUnshared = GSBlock, GSLocalMemoryMultiISA, GSXXH, GSVertexTraceFMM, GSRendererHWMultiISA, GSDrawScanline, GSRasterizer, GSRendererSW; plus x86 GSDrawScanlineCodeGenerator.all.cpp and GSSetupPrimCodeGenerator.all.cpp (arm64 .arm64.cpp variants).
   - Renderers: OpenGL (USE_OPENGL, glad, GLContextWGL on Win); Vulkan (USE_VULKAN: GSDeviceVK, GSTextureVK, vk_mem_alloc, VK*.cpp, needs vulkan-headers and SHADERC_INCLUDE_DIR); DX11/DX12 (WIN32: d3d11.lib, d3d12.lib, dxgi.lib, dxcompiler.lib, D3D12MemAlloc); Metal (APPLE only); SW and Null in common lists.
   - MultiISA gate: if(DISABLE_ADVANCE_SIMD AND ARCH_X86). Defines MULTI_ISA_SHARED_COMPILATION on PCSX2. foreach isa in sse4, avx, avx2 -> add_library(GS-${isa} STATIC ${pcsx2GSSourcesUnshared} ${pcsx2IPUSourcesUnshared} ${pcsx2SPU2SourcesUnshared}) with MULTI_ISA_UNSHARED_COMPILATION=isa_${isa}. Linked WHOLE_ARCHIVE (CMake 3.24+). MSVC flags: avx2 /arch:AVX2, avx /arch:AVX; no sse4 flag (SSE4.1 is baseline on MSVC in this mode).
   - Unshared set also pulls IPU/IPU_MultiISA.cpp, IPU/IPUdither.cpp, IPU/yuv2rgb.cpp, SPU2/Mixer.cpp, SPU2/ReverbResample.cpp.
2. MultiISA.h: namespaces isa_sse4 / isa_avx / isa_avx2 / isa_native. Macros: CURRENT_ISA, MULTI_ISA_UNSHARED_START/END/IMPL, MULTI_ISA_COMPILE_ONCE, MULTI_ISA_DEF, MULTI_ISA_FRIEND, MULTI_ISA_SELECT (picks by g_cpu.vectorISA: SSE4/AVX/AVX2). Single-ISA: MULTI_ISA_SELECT(fn) -> isa_native::fn. Runtime: ProcessorFeatures g_cpu with VectorISA enum {SSE4, AVX, AVX2, AVX512F}.
   - Decision: for PS2Recomp, the simplest is single-ISA (isa_native, DISABLE_ADVANCE_SIMD=OFF or ON without the MultiISA gate) at SSE4.1 baseline; MultiISA only matters if you want runtime AVX2 selection. If DISABLE_ADVANCE_SIMD is ON on MSVC, MultiISA is used and you must link all three GS-* libs.
3. Build options (cmake/BuildParameters.cmake): USE_OPENGL ON, USE_VULKAN ON, DISABLE_ADVANCE_SIMD OFF, USE_VTUNE, X11_API/WAYLAND_API/USE_BACKTRACE/USE_LINKED_FFMPEG (Unix only). ENABLE_VULKAN and ENABLE_OPENGL are appended to PCSX2_DEFS, not options. ARCH_X86 adds _M_X86=1 and __SSE4_1__=1 on MSVC. CMAKE_CXX_STANDARD 20. Top CMake: min 3.16...3.25, supports Clang and MSVC.
4. Dependencies:

   - Stub list (GS.cpp): Host::AddIconOSDMessage, Host::AddKeyedOSDMessage, Host::ReportErrorAsync, Host::ReleaseRenderWindow; VMManager::HasValidVM; Pcsx2Config::GSOptions::GetRendererName, GSOptions::RestartOptionsAreEqual; MTGS::RunOnGSThread, WaitGS, ToggleSoftwareRendering, ApplySettings; EmuConfig/GSConfig globals; GSGetBaseVideoFilename.
   - Vendored under 3rdparty/ (no submodules shown): fmt, imgui, xbyak (xbyak/xbyak), vulkan (Vulkan headers), d3d12memalloc, zydis (x86), glad (OpenGL), libzip, lzma, rapidjson, rcheevos, simpleini, cpuinfo, soundtouch, fast_float, demangler, etc. Note: no xbyak or VulkanMemoryAllocator confirmed in find_package list; xbyak and vk_mem_alloc appear via 3rdparty/xbyak and GS source.

   - build-dependencies.bat (VS2022, vcvars64) builds from source with pinned SHA-256: zstd 1.5.7, libpng 1.6.58, libwebp 1.6.0, libjpeg-turbo 3.2.0, lz4, zlib, rapidyaml 0.12.1, DirectX-Headers 1.619.5, dxcompiler 1.9.2609.5 (NuGet prebuilt .lib/.dll), shaderc 2026.2 (source, with glslang 275822a, SPIRV-Headers 58006c9, SPIRV-Tools 6337eb6). NOT in the script: lzma, libzip, imgui, fmt (vendored in 3rdparty/).
   - Vulkan shaders: shaderc is loaded at runtime via dyn_shaderc (DynamicLibrary, SHADERC_FUNCTIONS), not linked. Shader cache at EmuFolders::Cache (vulkan_shaders .idx/.bin, vulkan_pipelines.bin). So shaderc DLL (shaderc_shared) must ship next to exe, or you stub the Vulkan path.
   - DX11 shaders compiled by D3DCompile at runtime; d3dcompiler_47 system DLL.
5. Shaders: pcsx2/bin/resources/shaders/{common, dx11, opengl, vulkan} (no dx12 or metal folder at this tag). Loaded by GSDevice::ReadShaderSource -> FileSystem::ReadFileToString(Path::Combine(EmuFolders::Resources, filename)) unless BAKE_SHADERS_IN_CPP is defined (then s_baked_shaders map). Files: vulkan/{cas, convert, imgui, interlace, merge, present, shadeboost, tfx}.glsl; dx11/{cas.hlsl, convert/imgui/interlace/merge/present/shadeboost/tfx .fx}; common/{fxaa.fx, ffx_a.h, ffx_cas.h}. Runner must ship bin/resources/shaders/** next to exe, or define BAKE_SHADERS_IN_CPP (not verified in build files).
6. Size: pcsx2/GS has 50 top-level files plus Renderers/ (subfolders Common, DX11, DX12, HW, Metal, Null, OpenGL, SW, Vulkan) and docs/. Byte size NOT measured (listing shows no sizes). Sparse checkout is practical with `git sparse-checkout` on those paths, but CMake's top-level add_subdirectory(common), add_subdirectory(pcsx2) and many 3rdparty adds need matching folders.

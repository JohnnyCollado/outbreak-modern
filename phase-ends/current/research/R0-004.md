## Findings
(2) Design decisions (docs/native-port-design.md; there are 6, no Decision 7):
- D1 static recompilation, decomp C per function over time (:28-50). Why: playable from recompiler day one, native speed, one generated C for all platforms.
- D2 every game pointer is a 32-bit PS2 address in a 4 GiB reserved block (:52-69). Why: data layout identical byte-for-byte across platforms (packets, saves).
- D3 SDL3 + Vulkan + sockets/mbedTLS + CMake (:71-79). Why: one API per platform; KDDI pages need legacy TLS. CONFLICT: PS2Recomp uses raylib (m0-decision.md:55; m1-skeleton.md:18-20).
- D4 HLE system libraries at the call, shared; IOP never emulated (:81-93).
- D5 logic at 30 Hz everywhere, from display timing (:95-98). Why: online play needs it.
- D6 visuals are presentation only (:100-158). Why: cross-play safe; texture keys follow PCSX2.

## Answer
- Screenshot Resolution = "Internal Resolution (Aspect Uncorrected)" (`GSScreenshotSize::InternalResolutionUncorrected`) is the only mode that outputs the raw GS render-target size with no aspect stretch. At 1x native, output = texture width x height, which is 512x448 only if the GS target is 512 wide (unverified, see below).
- Other modes do not give 512x448: "Display Resolution" (WindowResolution, default) outputs the on-screen picture rect at window size; "Internal Resolution" (aspect-corrected) stretches width to the display aspect (512x448 -> about 597x448 at 4:3 by my arithmetic, not run).
- Format: PNG default. Quality 90 (only matters for JPEG/WebP).

## Findings
1. Settings (source: pcsx2/Config.h, GSOptions; pcsx2-qt GraphicsSettingsWidget.cpp via fetch):
   - enum GSScreenshotSize { WindowResolution, InternalResolution, InternalResolutionUncorrected }; default WindowResolution.
   - enum GSScreenshotFormat { PNG, JPEG, WebP, Count }; default PNG. ScreenshotQuality default 90. PNGCompressionLevel default 1.
   - Qt row labels: "Screenshot Resolution" (key ScreenshotSize, EmuCore/GS), "Screenshot Format" (ScreenshotFormat), "Screenshot Quality" (ScreenshotQuality). Dropdown display strings not located (not in GraphicsSettingsWidget.cpp; probably .ui/translation).
   - Files: GSGetBaseSnapshotFilename() returns Path::Combine(EmuFolders::Snapshots, GSGetBaseFilename()); OrganizeSnapshotsByGame adds per-game subfolder. GSGetBaseFilename = title + disc serial + strftime "%Y%m%d%H%M%S"; same-second collisions get "_(n)" from 2. Exact field order and title limit not verified. Extension from ScreenshotFormat. Encoding runs on worker threads (GSJoinSnapshotThreads).
2. Geometry (GSRenderer.cpp, GSRenderer::SaveSnapshotToMemory, fetched; quoted by summary tool, verify):
   - VSync: internal_resolution = ScreenshotSize >= InternalResolution; aspect_correct = ScreenshotSize != InternalResolutionUncorrected; calls SaveSnapshotToMemory(internal ? 0 : window_w, internal ? 0 : window_h, aspect_correct, crop_borders=true, ...).
   - window 0 + apply_aspect: expand texture to GetCurrentAspectRatioFloat (wider of tex/aspect).
   - window 0 + no aspect: draw_rect = current->GetWidth() x GetHeight() (raw texture).
   - window given: CalculateDrawDstRect(window, src_rect, ...) -> window-dependent size.
   - image_w/h = draw_w/h when crop_borders (true in VSync), so no letterbox bars.
   - Source rect = CalculateDrawSrcRect (includes GSConfig.Crop) but output size is still draw_rect; so with Crop set, the crop region is likely stretched to full output size. Unverified: set Crop to 0.
   - Snapshot reads g_gs_device->GetCurrent() after Merge (so deinterlace/ShadeBoost/FXAA applied); TV shader/CAS are in the present path and not in the readback (per summary). OSD not included.
   - Readback: StretchRect with ShaderConvert::TRANSPARENCY_FILTER, bilinear flag always set, to a draw_w x draw_h target. At exact 1:1 the bilinear pass should be identity but unverified.
   - BilinearSharp present: VSync resizes the device to internal res before snapshot (if current texture is larger).
   - GS dump path: separate fixed 640x480 SaveSnapshotToMemory, not user-controlled.
   - Pin for 512x448 output: Screenshot Resolution = Internal Resolution (Aspect Uncorrected); Crop = 0; Screenshot Format = PNG; internal resolution 1x (Internal Resolution = 1x, not "Auto" if it resolves >1x); window/aspect settings do not affect this mode.
3. Not verified (no source fetched): Deinterlace modes and their effect on 448-line frames; Dithering/Blending in SW renderer; Integer scaling/Screen Offsets/Overscan effect (window-mode only per code path); FMV aspect override.
4. Automation: CLI per pcsx2.net docs (pcsx2.net/docs/advanced/cli): -batch exits after shutdown; -nogui implies batch; -state N and -statefile FILE; -fullscreen; -turbo/-unlimited; args after "--". -gsdump replay not found in docs (unverified). Hotkey F8 = screenshot (fan wiki, not official). QueueSnapshot(path, frames): path may be full ".png" path (extension stripped) or empty for default name.

## Answer
- Not in-process. GT4Recomp (game, Vulkan-free host side) talks to a separate GPL process `gt4-gs.exe` over shared memory: SPSC rings, named mapping, wake events, Job Object, `--parent` pid check.
- Build = full PCSX2 v2.8.2 tree (CMake target `pcsx2-gt4gs`) with JIT removed (`GT4GS_ONLY=ON`, `GT4GS_NO_JIT`), not GS+common only. Interpreters + C rasterizer kept.
- Protocol (`3rdparty/gt4recomp-gs-stream/gs_stream_protocol.h`, MIT, vendored, "protocol 1.2" with 1.3 CONTROL kind 7 defined locally). Message set matches the brief's list, plus `STATE_SAVE/LOAD`, `AUX_FRAME_*` (reserved, answered ERROR), `OSD_STATS` (11).
- Readback is request/response in a response area; the producer blocks on it (no batching of READ_FIFO; it signals immediately).
- Mismatch with brief: the protocol doc gives "~320 event signals/frame without batching, 11-14 with it" (not 322->12). 59.9 FPS, 0.93 ms readback were NOT found in any page I read.

## Findings

Also `pcsx2-gt4gs/StreamTransport.cpp` wraps the C++-exception transport, exposing a no-throw interface.
5. Protocol header (raw, fetched 2026-10-22): magic `0x54535347` ("GSST"), major 1 (refuse mismatch), minor 2. Records 16-byte aligned; header = type u16, flags u16, payload_bytes u32, sequence u64.
   - Producer->consumer: GIF=1, PRIV=2, VSYNC=3, READ_FIFO=4, RESET=5, CONTROL=6, STATE_SAVE=7, STATE_LOAD=8, AUX_FRAME_BEGIN/END=9/10 (ERROR unsupported), OSD_STATS=11.
   - Consumer->producer: READY 0x81, STATS 0x82, ERROR 0x83, SNAPSHOT_DONE 0x84, WINDOW 0x85, EXITING 0x86.
   - GIF: `path` u8 (1=VU1 XGKICK, 2=VIF1 DIRECT/HL, 3=GIF DMA/FIFO), `flags` (bit0 kGifFlagSignalsApplied), `bytes` u32 (GIF bytes after struct, 16-multiple). Large chunks split with kRecordFlagMore.
   - PRIV: `address` u32, `value` u64. Only the 8 KiB privileged block at 0x12000000 (kPrivilegedBytes 0x2000). CSR bit 9 = GS reset request; writing 1 to CSR bits 0-4 clears IRQ flags. Single register write per record, not whole block.
   - VSYNC: `frame` u64 (0 first, +1), `field` u8 (CSR FIELD bit 13, 1=odd), `flags` bit0 kVsyncFlagFieldValid. Consumer uses field as-is when valid, otherwise alternates.
   - READ_FIFO: `qwords` u32 (<= response_capacity/16), `request_id` u64 = control-block readback_request. Consumer runs earlier records, writes qwords*16 bytes to response area, sets readback_status (0 ok, 1 zero-filled, 2 failed) and completes request_id.
   - RESET: `kind` u32 (gs_hard=1, gif_paths=2), `path_mask` u32 (bits 1-3).
   - CONTROL (32 B): `kind` u32 (shutdown 1, attach_window 2, resize 3, reload_config 4, snapshot 5, cursor 6; 1.3 display_aspect 7 = args[0] 0 game/1 fill), `args[3]` u64. Snapshot answered with SNAPSHOT_DONE (id,w,h,response_offset,bytes RGBA8).
   - Back-channel: READY (144 B, version_minor, flags incl. kReadyFlagReadbacksZeroFilled=1, Presents=2, Records=4, OsdStats=8); STATS (8 x u64: vsyncs, records, bytes, readbacks, readbacks_zero_filled, busy_us, wait_us) every 500 vsyncs + shutdown; ERROR (code 1-6, fatal, text[248]); WINDOW (lost/restored); EXITING.
   - Sizes: command ring 32 MiB, response 4 MiB+64 KiB, event ring 256 KiB.
   - Control block (4 KiB): frames_in_flight_limit 1-3 (default 2; env GT4_GS_FRAMES_IN_FLIGHT); readback_request/done/bytes/status at 512-536; heartbeats at 576; waiter flags at 384.
6. Interrupts/SIGNAL/FINISH/IMR: NOT reported back over the stream. Producer (game side) applies PATH2/3 SIGNAL/FINISH/LABEL on EE at acceptance and PATH1 at render point; EE reads of CSR/IMR/SIGLBLID answered locally. Consumer CSR copy only needs FIELD and RESET.
7. READ_FIFO latency: "not quantified" in protocol doc. Requests > response area split. If consumer dies, game answers readbacks with zeros. Unsynchronized readback (HWDownloadMode 3) answers from CPU copy, so GPU pixels may be stale (known problem, gt4gs README).
8. Batching: GIF/PRIV may defer wake until GT4_GS_WAKE_BYTES (default 256 KiB; 0 = every record); others signal immediately. Waiters spin 30 us then sleep in <=100 ms slices. Figure: "about 320 event signals per frame without batching, 11-14 with it" (headless race).
9. Deinterlace/pacing: 1.1 VSYNC field fix (PR #31, TASK-047) so 480i menus weave correctly under PCSX2 Automatic. DeferSwapChainAcquire default true (0.3.0) avoids blocking GS thread on FIFO. GT4GS SpinUs default 30. Readback timing printed every 500 vsyncs.
10. Fixed issues via PRs: 1.0.1 stopped writes to Documents\PCSX2 (PR #38); 0.3.0 ini folder keys + early acquire (PR history); PR #37 cursor auto-hide, shader notice, perf overlay; PR #46 MSI Afterburner/RivaTuner overlay compat (ACG off default); PR #33 JIT-free build (GT4GS_ONLY, ACG).
11. Repo activity: gt4-staticrecomp 79 closed PRs, 0 open except dependabot #1 (gt4recomp-gs has 1 open PR). Latest merges Oct 22 2026. gt4recomp-gs: 22,568 commits, 0 stars/forks.
12. Other in-process users: none found. PS2Recomp (ran-j/PS2Recomp, GPL-3.0, static recompiler, no GS renderer yet per coverage; v0.3 notes mention GS local-to-local transfer and PSMT8) does not use PCSX2 GS.

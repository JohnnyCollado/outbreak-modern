Decisions:
- binding: never call `GSReadLocalMemoryUnsync` for diagnostics or snapshots (mutates PCSX2 transfer state); read `g_gs_renderer->m_mem`.
- binding: the adapter's synthetic-IMAGE-tag strip couples it to ps2_vif1_interpreter.cpp:307-323; pay the debt (PS2Recomp patch flagging those packets in the arbiter) before Android.
- Snapshot = 1:1 crop of the displayed rect from PCSX2 local memory (circuit 1 if enabled else 2, no two-circuit blend); kept because shares were equal and it no longer depends on PCSX2's snapshot texture size.
- Readback uses `GSInitAndReadFIFO`; the CPU backend is still drained so its transfer state is unchanged.
- Per-path carry: only whole GIFtag units go to PCSX2; only an open IMAGE unit carries to the next packet.

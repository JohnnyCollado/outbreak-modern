Decisions:
- binding: scripted boots step on the guest vsync (EeScheduler VBlankStart), never host frames; with a script the pad is script-only (no host input) — the determinism the gate relies on.
- Capture takes the next n distinct latched ticks; the host loop can skip a tick, so the k-th frame may differ by one tick between runs (title-2 above).
- `watch` step added beyond the done-when's minimum: the only way to confirm decomp addresses empirically.

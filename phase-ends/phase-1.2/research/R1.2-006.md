Output size (GSRendererSW::GetOutput): w = curFramebuffer.FBW * 64; h = PCRTCDisplays.GetFramebufferSize(i).y; ResizeRenderTarget(w,h); scale = 1.0f. Rect from GetFramebufferRect(i); offsets masked to 11 bits. Display rect formula (DW/MAGH) was NOT found in fetched code. Hardware formula (unverified here): width = (DW+1)/(MAGH+1). DW=2559, MAGH=4 gives 512, consistent with that.

Interlace (GSRenderer::Merge, GSDevice::Interlace):
- game_deinterlacing = framebuffer Y-offset change across both circuits (not SMODE2 INT/FFMD).
- Defaults field2=0, mode=3. Automatic gate: if InterlaceMode != Automatic OR (!game_deinterlacing && !SMODE2.FFMD && !scanmask_frame), then field2=((mode-2)&1), mode=((mode-2)>>1).
- Quirk: for Automatic (0) inside the gate this yields mode=-1, which falls to the default case (m_current=m_merge, i.e., no interlace). Unverified; check before relying on it.
- Consequence: Automatic in field mode (FFMD=0, INT=1) -> likely no deinterlace (quirk); Automatic in frame mode (FFMD=1) -> mode stays 3 = Adaptive/FastMAD.
- Final call: if ((tex[0]||tex[1]) && isReallyInterlaced() && InterlaceMode != Off) Interlace(fs, field ^ field2, mode, offset). offset=0 unless bob.
- Mode dispatch: 0 Weave (Nearest), 1 Bob (Biln, yoffset*(1-field), half-line shift so NOT pixel identical), 2 Blend (Weave then Biln blend), 3 FastMAD (MAD_BUFFER + MAD_RECONSTRUCT), default no-op.
- DisableInterlaceOffset forces offset=0.

Bilinear at 1:1: GSDevice StretchRectAuto turns bilinear into a shader filter (Biln) when supported; Resize hardcodes Nearest. Did not verify that Biln at exact 1:1 samples texel centers, so pixel-identity is unconfirmed. Safer: linear_present_mode=Off for the reference.

Portable (pcsx2.net/docs/configuration/general): create empty portable.txt or portable.ini beside pcsx2.exe, or launch with -portable. Docs give no inis/ or snaps/ paths. Forum (dated) says inis beside exe in portable mode. snaps/ default unverified. Screenshot folder ini key not found.

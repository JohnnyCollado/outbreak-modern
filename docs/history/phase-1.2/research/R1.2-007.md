## Answer
1. 5-bit to 8-bit expansion is zero-fill (c<<3), not bit replication. Max per-channel gap vs (c<<3)|(c>>2) is 7 (c=31).
2. Dithering: GSConfig Dithering default 2 (Unscaled). The SW renderer reads only the DTHE register (not the GSConfig value). Dither is applied only on 16-bit framebuffer writes, at draw time.
3. PCRTCAntiBlur (default true) only changes framebuffer/display offsets (sub-4-pixel adjustments); not applied when scanmask is set. Max effect size not quantified.
4. Not resolved. Merge keys on SMODE2.FFMD only (SMODE2.INT is not referenced). The line-doubling/interleave is done in the device Interlace() pass, which I did not read.
5. DIMX default values: NOT FOUND. ExpandDIMX definition: NOT FOUND. Application is at draw time in GSDrawScanline.
